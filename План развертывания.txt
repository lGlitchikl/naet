1) Установка Next JS
 npx create-next-app@latest имя-проекта
 cd имя-проекта
2) Настройка переменных окружения
В корне проекта создайте файл .env (если его нет) и пропишите:
 DATABASE_URL="mysql://root:ваш_пароль@localhost:3306/prisma"
 AUTH_SECRET="любая-случайная-строка"
 AUTH_TRUST_HOST=true
(Замените ваш_пароль на пароль от вашего MySQL).
3) Перенести все фаилы из папки nao с заменой
4) Настройка базы данных
Откройте phpMyAdmin (http://localhost/phpmyadmin).
Создайте новую базу данных, назовите её prisma.
Выберите эту базу и перейдите на вкладку «Импорт».
Нажмите «Выберите файл» и укажите файл database_dump.sql (который лежит в корне проекта).
Нажмите «Вперед» (Go). Все таблицы и данные (курсы, тесты, новости) импортируются автоматически.
5) Установите зависимости:
 npm install
Соберите проект:
 npm run build
Запустите:
 npm run start
